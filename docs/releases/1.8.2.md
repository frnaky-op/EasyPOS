# EasyPOS 1.8.2

This release fixes the Windows installer startup screen staying on “Please wait...”. The 1.8.1 installer omitted the renderer JavaScript and CSS bundles, so the desktop interface could not initialize.

The release build now generates those bundles before packaging and verifies that both are present inside the Electron application archive. The application and shop data remain in the same locations.

Download `EasyPOS-Setup-1.8.2-x64.exe` and install it over 1.8.1. Existing shop data is retained. As usual, keep a backup of your shop data before upgrading.
