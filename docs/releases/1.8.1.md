# EasyPOS 1.8.1

This release delivers the mobile catalogue and checkout introduced in the 1.8 series, together with the redesigned [project website](https://frnaky-op.github.io/EasyPOS/) and [illustrated user guide](https://frnaky-op.github.io/EasyPOS/guide.html).

## What is included

- Pair a phone on the same trusted Wi-Fi, photograph a barcode, and create or edit products with photos, prices, categories, and stock.
- Use the mobile caisse to browse products, manage cart quantities, choose a customer and payment method, and record a paid sale. The server checks current prices and stock.
- Use the updated desktop logo, navigation, themes, and photo-led product grid.
- Follow the new installation and usage guide for supplier receiving, barcode PDF sheets, backups, and updates.

## Why 1.8.1

The first 1.8.0 publish attempt created duplicate GitHub release records and left the latest one without a complete set of update assets. Version 1.8.1 is built from the same feature set with a release workflow that uploads the installer, blockmap, and `latest.yml` together after a successful build.

## Install or update

Download `EasyPOS-Setup-1.8.1-x64.exe` from this release. Installed NSIS copies can also check **Paramètres → Mises à jour** and install the new version when ready. Back up shop data before upgrading. Older Forge/Squirrel installations need one manual NSIS installation first; the internal `PharmaSpot` data directory remains unchanged.

The mobile interface uses local HTTP on port 3211. Keep the PC and phone on a trusted Wi-Fi network. Barcode scanning uses a photo rather than continuous live video on this local address.
