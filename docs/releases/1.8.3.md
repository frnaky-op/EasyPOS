# EasyPOS 1.8.3

This release makes phone pairing work on a standard Windows installation without asking each shop owner to change the Wi-Fi network profile manually.

During installation, Windows asks once for administrator approval to allow the EasyPOS mobile service through the firewall. The rule is restricted to the EasyPOS executable, TCP port 3211, and devices on the same local subnet. It also works when Windows calls the Wi-Fi network Public. Uninstalling EasyPOS removes the rule.

Keep the PC and phone on the same shop Wi-Fi. A guest network that isolates devices, a VPN, or a company firewall policy can still prevent local connections. The desktop API stays bound to loopback.

The installer now includes the Android companion APK. Scan **Accès mobile** on the PC and tap **Télécharger l’application Android**, or download the APK directly from this GitHub release. The release build verifies the APK checksum and fails if the phone app is missing.
