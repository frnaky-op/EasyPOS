# EasyPOS 1.6.0

This release introduces a Windows installer and a release-based update path. Installed copies check GitHub Releases at startup and can check again from **Paramètres → Mises à jour**. When a new version finishes downloading, choose **Installer et redémarrer**.

It also includes the new **Fournisseurs** directory, supplier selection in products and receptions, and the latest catalogue and stock improvements.

**Upgrading from an older Forge/Squirrel installer:** install this version manually once. Later NSIS releases can update from inside EasyPOS. The internal `PharmaSpot` data directory is unchanged, but make a backup before changing installers.

The Windows installer is currently unsigned, so Windows may show a SmartScreen warning. The source code and release workflow are available in this repository.
